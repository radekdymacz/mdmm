# Machinedrum Editor + Monomachine Editor 0.6.0

The biggest release so far: the editors now do what the Machinedrum and Monomachine manuals describe, as far as that can be done from outside the machine. There is a user guide that follows the manuals' chapters, a long list of new features on both editors, and many fixes from your reports and from running every function against the real firmware.

A release on top of [0.5.1](https://github.com/radekdymacz/mdmm/blob/main/doc/release/v0.5.1.md). Screenshots, features and FAQ: **https://mdmm.dev** · User guide: **https://mdmm.dev/guide/**

## Feature parity with the manuals
- **265 of the Machinedrum's 280 functions and 336 of the Monomachine's 351** are in the editors, each with a test that uses it on the real firmware. The rest either need the machine's own hardware (a key combination the mouse makes pointless, the soft reset, the fixed PRG CHANGE channel) or are planned for 0.7 (the Machinedrum's sample manager features, SDS from other tools, the MKI model).
- **A user guide, in the manuals' order**: every chapter of both manuals, in our own words, with pictures taken from the editors themselves. On the site at https://mdmm.dev/guide/ and as a PDF for each machine. It also says where the editor works differently from the hardware.

## New, on both editors
- **Song slots.** Load, rename (F2), copy, paste, drag one slot onto another, Save to…, clear (it asks, and Cmd+Z brings it back). Switch between PATTERN, CHAIN and SONG. On a real machine over MIDI, Save to… waits as SEND n.
- **Transport.** Pause and continue (⇧-click ▶ or ⇧Space), a ▾ on ▶ with Play/Stop, Pause/Continue, Record and Panic (⌘.), a tempo control (−/+, TAP, +10 % / −10 %, ⌥-drag), and ▶ From here on the song page. In a DAW the tempo stays locked to the host.
- **Recording.** Hold Delete during live recording to erase the selected track as it plays (Machinedrum and Monomachine), and on the Monomachine step recording from the keyboard: a red cursor on the roll, → leaves a rest, ← goes back, Delete clears the step.
- **Copy, paste and clear "what".** The ▾ beside COPY, CLR and PASTE picks what goes: trigs, accent, slide, sound. Also the Machinedrum LFO card's Copy, Paste and Clear LFO. Keys ⌘⇧C, ⌘⇧V and ⌘⇧⌫.
- **GLOBAL as a page.** Both editors: copy, paste and clear a global slot. Machinedrum: Trig in A / B (the factory global reads Gate 1, Sens 0, Vmin 0, Vmax 127), and LEARN on a track to map a MIDI note to it. Monomachine: master tune and Control out 1.
- **SysEx import, export and reset** in the engine menu. Export all of the machine, or only the kits, patterns, songs, globals and waveforms you tick, and import to a place you choose. Verify only shows what would change. Reset machine…: an empty reset on both, a factory reset on the Machinedrum.
- **Machine memory for new sessions.** What you save on the machine (a kit, a pattern, a song, a global) is kept in a file, and a new session starts from it. A DAW project still opens with its own memory. Reset machine… > Start from factory memory…, and a KEEP MEMORY switch turn it off. The standalone starts from the file as well. Two instances of one machine: the last save wins.
- **Type a value.** ⌘-click a value (Ctrl-click on Windows), type, Enter. A value out of range is refused with its range; ⌘Z takes a typed value back.
- **Revert track.** The key beside the machine key puts one track back to what its kit slot stores.
- **The machine's own clock in a DAW.** GLOBAL > Sync > Tempo in INT lets the machine run on its own clock, saved with the project.
- **Incoming MIDI notes light up** the keys (Monomachine Perform) and the tracks (Machinedrum), in the standalone and in a DAW.
- **The Perform keyboard's keys** light only while a key is held.
- **UNDO KIT** brings back the kit that was playing after you loaded another without saving it.
- **GLOBAL, the kit library, AUDIO / MIDI, the machine picker and the SysEx panels** are dialogs: a click beside one leaves it open, Esc closes it.
- **The top bar and the LCD fit** at every window size down to about 864 px wide, on every workspace.
- **Solo is saved with the DAW project.**

## New, Machinedrum
- **A LEV box above each Mix strip**: the track's level, separate from VOL, with undo.
- **Try a machine before you choose it.** In the machine picker, ▶ puts the machine on the track and plays it once; Esc puts the old one back with its sound; Enter keeps it.
- **Paint swing, accent and slide** with the keys under the grid, for all tracks or the one you are on.
- **Parameter relations** are drawn as an arch over the knobs they link (RAMP and RDEC, AMD and AMF…).
- **Sampler: Rename.** Renames a ROM slot's sample on the machine, audio unchanged.
- **Pattern length** 32 or 64 repeats the existing pages, and a queued pattern shows as the current one when you stop.
- **A song row with a repeat** shows +2, +1, last as it plays.
- **A cleared kit slot** loads as a really empty kit.

## New, Monomachine
- **MKI and MKII plate key.** The LCD is light blue on MKI and bluish white on MKII; the machine list greys the MKII-only machines on MKI.
- **Perform: Poly**, filter key tracking and the Multi envelope are easy to set up (a track's six voices, LPF tracks keys, the envelope's hint about the Multi trig mode). The Multi map's pattern list runs A01 to H16.
- **A trig's marks on the roll.** Which envelopes a note fires, locks, slides, swing, trigless trigs and NOTE OFF show on the note itself, and the right-click menu sets each one for every selected step. Clear locks keeps the notes. A lock key in the lock lane's header puts a lock at the kit's current value on every selected note.
- **The pattern chooser** can give a pattern a kit (⌥-click, then the Kit list), and **the arrangement** counts bars and beats as the song plays.
- **A foot to the Monomachine roll.** The Note, Slide and Swing row is gone; the roll is taller.

## Changed
- **The Monomachine roll has no draw mode any more.** A click on an empty step adds a note, dragging a note's end lengthens it, dragging its body moves it, and **Ctrl/⌘ selects** (drag on the ruler or the grid to box select). One solid gate bar replaces the old marks, which show only where there is something to show. If you used the pencil, this is the main difference to learn.
- **Import and Export SysEx are in the engine menu** (the kit library and the pattern chooser no longer have SysEx keys). A .syx dropped on the window still opens the import.

## Fixes
- **Monomachine: a track kept playing after the host's transport stopped, until a note was played on it** (B-121, from Discord).
- **Monomachine: mute and solo seemed to stop responding after switching views, and a solo lit in Mix but not in Sequence** (B-120, from Discord).
- **Monomachine: an imported global's MIDI channels reach the machine** (B-071).
- **Monomachine: ▶ after a pause, Panic and PLAY right after an edit** no longer refuse ("The panel is busy") or play silence while the machine takes an edit (B-099, B-129, B-135).
- **Monomachine: Play from a song row** starts in the row you picked after the song was edited (B-137), and a multi trig's setting no longer jumps back while the machine takes it (B-136).
- **Monomachine: RECORD** during a dump waits and starts when the dump is in (B-092); a pattern with chords no longer says "chord notes but no trig" (B-093).
- **Machinedrum: the first PLAY after start-up, and the first factory song, now play** (B-109, B-098).
- **Machinedrum: a value moved during live recording is recorded as a lock** (B-134), live erase no longer sets a trig on another track (B-101), and Chain works after a live recording (B-127).
- **Machinedrum: Undo straight after an Alt-drag** (a sweep on every track) now reaches the machine; the sweep no longer stays on the machine while the page shows it undone (B-145).
- **Machinedrum: a kit with a CTR machine on a track** no longer refuses every later edit (B-131).
- **Machinedrum: a pattern made 64 steps long from 48** repeats the right steps (B-103).
- **Machinedrum: the Rhythm Echo and Gate Box cards on Mix** show their own values (B-081); four E12 machines and the MID machines' routing knobs have their right names (B-080, B-082).
- **Both: a swing mark no longer flashes back on a step whose trig you removed** (B-070); the lock parameter keys show their names whole (B-097); the SysEx import panel keeps its size while it runs (B-095); the GLOBAL page's Trig in A / B shows its values under the right names (B-069).
- **Both: dialogs stay open on a click beside them** (B-094); text that was cut at the edge of a panel, a card or a list was fitted in the Machinedrum and Monomachine editors (B-111 to B-117, B-126).
- **Both: a pause right after PLAY** no longer ends at once (B-086), and ⇧-click on PLAY in the Monomachine shows paused (B-104).
- **Both: solo is kept in the saved project** (B-123).
- **Both: a step menu's ⋯ key** no longer covers its step (B-125).

## Known
- **Machinedrum: after a sample is sent to the machine by SDS (Load sample, a dropped file, a rename), live recording records nothing until the machine is restarted** (B-133). Look for it if live recording goes quiet after you work in the Sampler: restart the machine before live recording. The sample itself is fine, and so is the rest of the machine.
- **Machinedrum: a SysEx import and the empty reset cannot be undone** (B-130). Export a backup first.
- **Monomachine Sound: the UNISON and SUB screens' stems can look thicker than they should in the standalone** (B-132).
- **Window resizing:** the Monomachine window does not resize with the mouse, and the Machinedrum looks distorted when resized (B-063). Waiting for a tester's host and screenshots.
- **Machinedrum: in a small window the top bar's right end is cut** (B-061 is fixed down to 864 px wide; below that it can still run past the edge).
- **Machinedrum: a lock on a step without a trig is kept but not played** (I-019). OS 1.63 does this on the real machine too.
- **A song's LOOP row in the Monomachine** goes back to row 1 (B-038), and **a pattern pick during a SysEx import** asks about kit edits you never made (B-045).
- **Drag and drop works on macOS only** (I-017). On Windows and Linux, use the buttons.
- **The update banner still offers Download (the site), never Update** (I-005, waits for the signing key).
- **Two reports we could not reproduce and are still looking at:** Ableton Live seeming to route one editor's MIDI into the other (B-119), and "Reset to the pattern" loading another pattern (B-122). If you have steps, please send them: https://mdmm.dev/contact/

## Tips
- **Both editors open at once in Ableton Live:** in Live > Settings > Plug-Ins, turn **Multiple Plug-In Windows** on and **Auto-Hide Plug-In Windows** off.
- **The machine memory file** is `~/Documents/Gearmulator Preview/<Machine>/memory/machine-memory.bin`. If it is damaged the editor says so, starts from factory memory and keeps the damaged file as `machine-memory.unusable.bin`.

## Faster
- **The macOS profile (PGO) is trained again** on this code, so the macOS build uses it for every changed function.

## For developers
- **Every function is a row of data** in `doc/features/` (one file per machine), proved by a journey that names it (`proves:`); `scripts/mdmm-guide.mjs` writes the feature maps, the guide and its PDFs from the rows and the hand-written chapters. `scripts/mdmm-e2e.sh` runs every journey on the real firmware.
- **Journeys set up and tidy their own state** and can run shuffled or one by one; the last order-dependent ones were fixed.

## Platforms
- macOS 12 or later (Intel and Apple silicon), not signed by Apple yet: the first install needs **Open Anyway** (on macOS 12 to 14: right-click the installer > **Open**).
- Windows x64 and Linux x64: not tested by a person yet. Feedback welcome: https://mdmm.dev/contact/
