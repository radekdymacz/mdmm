# Keyboard shortcuts
<!-- summary: Every key of both editors, built from the editors' own key maps. -->

Press [?] in an editor for its own list, which is built from the same key map. [⌘] is Command, [⌥] is Option, [⇧] is Shift. On Windows, [⌘] is Ctrl and [⌥] is Alt. A plain letter acts on the selected track. [⌥] means all tracks. **MD** means the Machinedrum Editor only, **MM** the Monomachine Editor only.

### Selecting steps (MD)

Select one step or a block of steps across tracks, then copy, cut, paste or duplicate it. The selection is outlined and stays when you change pattern, so it is also where a paste goes. Each operation is one undo step. To copy one step to another: [⌘] click it, [⌘] [C], [⌘] click the step it goes to, [⌘] [V] (or Copy and Paste on the LCD, which act on the selection while there is one). Right-click a step for its menu: trig, accent, slide, copy, cut, paste, duplicate, clear and the every 2nd / 4th fill. [Delete] clears only selected steps; Clr on the LCD clears the page shown.
