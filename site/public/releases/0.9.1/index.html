Machinedrum Editor + Monomachine Editor 0.9.1

Released 2026-11-14

The follow-up to 0.9.0, made from what users reported. The Monomachine stops for real when the DAW stops, and it gets a factory reset. The Control page's knob rows can be mapped to DAW macros. The ROM folder can hold several images.

A release on top of 0.9.0. Screenshots, features and FAQ: https://mdmm.dev · User guide: https://mdmm.dev/guide/

New, Monomachine

  • Factory reset (B-211, MM-318). The engine menu's Reset machine… now has Factory reset…, as the Machinedrum has. The editor asks twice. A second Monomachine is started from your own ROM, and its factory kits, patterns and songs are sent to the machine, read back and reported in the SysEx panel. It takes seconds to prepare and minutes to send. Globals and user waveforms stay. One Undo puts your kits, patterns and songs back. No factory data is shipped with the editor.
  • Perform: joystick HOLD, RANDOM and REGION (I-061). The joystick can hold its position, and it can move at random inside a region you set.
  • Perform: the keyboard follows the octave of a played note (I-062).
  • Multi map opens as a dialog (I-064).

New, both editors

  • Knob 1 to 8 are host parameters (B-205). The Control page's eight knob rows now show in the DAW as Knob 1 to Knob 8, in the group Control after the tracks. Map them to a Rack macro in Ableton Live, a Push or any host controller. A change from the host drives the knob row. A CC on a knob row, or a drag on the page, reaches the host.
  • Several ROM images in the ROM folder (I-071). LOAD ROM no longer deletes the other images in the folder. A file you choose is added, or used where it is. Each instance runs the image it was given, and the project keeps the choice. REMOVE moves the image to the folder removed inside the ROM folder. Nothing is deleted.
  • One look (I-063). The whites and blacks are shared by the skins, the PATTERN and KIT choosers show 16 slots per row in both editors, and the track lists use one set of sizes.

Fixes

  • Monomachine in a DAW: the host's Stop is a real stop, and LOAD SONG works after it (B-210). MIDI Stop is a pause on the Monomachine, so after Play and Stop in the DAW the machine kept its song and ignored LOAD SONG, also when it was sent as SysEx from the DAW. The machine is now stopped when the host stops.
  • Monomachine: the LOAD SONG message is true (B-210). The page says a song is the machine's song only after the machine shows it. If the machine kept its song, the message says so. While the machine is paused by the editor, LOAD SONG is refused with the reason.
  • Machinedrum: the Mix page fits its window (I-064). On a low window the faders get shorter, down to 64 px, and the page no longer scrolls.

Upgrade

  • Monomachine in a DAW: Play after Stop starts from the start. The host's Play after the host's Stop is always MIDI Start. A song you just loaded plays from its first row. If you move the DAW's play position while it is stopped and then press Play, the Monomachine starts from the start and does not join at the DAW's position. A jump while the DAW plays (a loop) is unchanged. The Machinedrum is unchanged.
  • Knob 1 to 8 are new parameters at the end of the list. The parameters that were there keep their places.

Known

  • Monomachine: LIVE RECORDING can record no lock after the GLOBAL base channel was changed (B-196). Still open.
  • Monomachine: Empty Reset was reported to leave K01 SUPERWAVES unchanged (B-175). It is not reproduced: the test on the firmware shows that the reset clears K01. If you see it, please send the version and the steps. Factory reset is new in this release and may be the reset you want.
  • Hardware MIDI is beta. Using the editor with a real Machinedrum or Monomachine over MIDI works, but it is tested only in part. It will be tested on both machines before 1.0.
  • Windows and Linux are community-tested. They are built and run by the tests on every change, and no person has tested every release. Please send your logs with Save Diagnostics.
  • Machinedrum: after a sample is sent by SDS, live recording records nothing until you restart the editor (B-133). The machine's OS 1.63 bug; the editor keeps the hardware's behaviour.
  • Monomachine: a GLOBAL change made while the editor is still reading the machine at project open may not reach the memory file (B-192).
  • Monomachine: two factory patterns did not play in one real-factory journey (B-198) and one 10.4 ms device-lock hold in a test (B-199). Each was seen once and is open; nothing a user reported.

Platforms

  • macOS 12 or later (Intel and Apple silicon), not signed by Apple yet: the first install needs Open Anyway (on macOS 12 to 14: right-click the installer > Open).
  • Windows x64 and Linux x64: community-tested. Feedback welcome: https://mdmm.dev/contact/
