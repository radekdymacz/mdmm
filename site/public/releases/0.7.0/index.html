Machinedrum Editor + Monomachine Editor 0.7.0

Released 2026-10-15

A release about the grid and the lanes: a small GEN dialog on every track, shape tools for the lock lane, and a new look for the Monomachine's lane row, Arp, Trig setup and Perform pages.

A release on top of 0.6.0. Screenshots, features and FAQ: https://mdmm.dev · User guide: https://mdmm.dev/guide/

New, on both editors

  • A dice key on each track, after M and S, opens a small GEN dialog. Pick Euclid or Random, set the MODE row, and the track changes as you turn the controls. Cancel puts the track back; Done keeps it. Either way it is one undo.
  • The GEN dialog stays out of your way. Drag it by its head. Change track while it is open and it follows. ESC closes it. A Keep switch holds what you have; ⌘-click the dice to keep without opening, and ⌥R rolls all tracks and keeps them.
  • The GEN bar under the grid is gone. The dice key replaces it.
  • Lane shape tools on the lock lane. Eight shapes, ×1, ×2 and ×4, every 2nd, 3rd or 4th step, offbeats, Human, scale and Inv. Hover a tool to see a preview on the lane before you apply it. ⌘ adds the shape to the lane, ⌥ subtracts it, ⇧ scales it.
  • Lane hover shows an outline only, so the values underneath stay readable.
  • Mix strip heads show the track number and the machine name, and a trig light that flashes on trigs and played notes.
  • Sound page: Clear sits next to R. It replaces Revert track on that page.
  • Long track names end with an ellipsis, and the full name shows as a tooltip.

New, Monomachine

  • Lane row: the tabs on the left, the tools on the right.
  • Arp has a LEN box. The strip shows the LEN steps, and the values sit under the strips.
  • Trig setup: the values sit under the graph, the graph is easier to read, and Legato has a restarts panel.
  • Perform page redesigned. The envelope covers all tracks on the left. The track card has a T1 to T6 selector, the joystick and assign. Mutes and the keyboard modes sit on the right.
  • ? help and 1/16 are now on the right of the roll bar.

New, Machinedrum

  • Sampler: the source choice and the take status are in the card heads. Source and Playback faders share one line.

Fixes

  • Firmware tests no longer crash when a SysEx import ends (B-147, test harness only).

Known

  • Machinedrum: after a sample is sent to the machine by SDS (Load sample, a dropped file, a rename), live recording records nothing until the machine is restarted (B-133). Restart the machine before live recording if you work in the Sampler first. The sample itself is fine, and so is the rest of the machine.
  • Machinedrum: a SysEx import and the empty reset cannot be undone (B-130). Export a backup first.
  • Monomachine Sound: the UNISON and SUB screens' stems can look thicker than they should in the standalone (B-132).
  • Window resizing: the Monomachine window does not resize with the mouse, and the Machinedrum looks distorted when resized (B-063).
  • Machinedrum: in a small window the top bar's right end is cut below 864 px wide (B-061).
  • Machinedrum: a lock on a step without a trig is kept but not played (I-019). OS 1.63 does this on the real machine too.
  • A song's LOOP row in the Monomachine goes back to row 1 (B-038), and a pattern pick during a SysEx import asks about kit edits you never made (B-045).
  • Drag and drop works on macOS only (I-017). On Windows and Linux, use the buttons.
  • The update banner still offers Download (the site), never Update (I-005, waits for the signing key).
  • Two reports we could not reproduce and are still looking at: Ableton Live seeming to route one editor's MIDI into the other (B-119), and "Reset to the pattern" loading another pattern (B-122). If you have steps, please send them: https://mdmm.dev/contact/

For developers

  • ROM-free page preview with live reload: scripts/mdmm-preview.sh md|mm. Data-driven scenarios (?scenario=, doc/modern-ux/scenarios) are checked against a schema.
  • The page suite runs in CI on every push to main: the page tests and the page-tier journeys of both editors, on Linux, no ROM.
  • The E2E run ends with a pass or fail verdict, and check selection is narrower by area.
  • Gate journeys start from factory memory, and the background meter reads -50 dB, so the six real-factory and real-sequence journeys can prove sound and pass.
  • B-147: firmware tests clear the import's SysEx tap when the import ends.

Platforms

  • macOS 12 or later (Intel and Apple silicon), not signed by Apple yet: the first install needs Open Anyway (on macOS 12 to 14: right-click the installer > Open).
  • Windows x64 and Linux x64: not tested by a person yet. Feedback welcome: https://mdmm.dev/contact/
