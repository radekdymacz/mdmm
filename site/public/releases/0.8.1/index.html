Machinedrum Editor + Monomachine Editor 0.8.1

Released 2026-10-29

A bug-fix release. The Monomachine starts a new kit with the values the machine itself uses, the keyboards match the machine's note range, and a number of smaller faults reported on Discord or found by the tests are closed.

A release on top of 0.8.0. Screenshots, features and FAQ: https://mdmm.dev · User guide: https://mdmm.dev/guide/

Monomachine

  • A new kit starts with the machine's own values (B-175, B-176). The start values of the AMP, FLT, EFX and LFO pages and of the SYN page of every machine are now those the firmware gives a new kit, read from the machine. A new kit no longer starts with AMP VOL at 100.
  • The piano keys run from C-0 to B-8 (B-185), the range the machine plays. Hover a key to see its note name. The Pattern roll still holds all 128 notes; only the keyboards stop at C-0 and B-8.
  • A note drawn in the roll no longer hangs when the arpeggiator is on (B-179). With KEY, SID or ADD on, a new note is held to the next trig, as a trig key does on the machine, so a single note repeats. With the arpeggiator off, the draw length is kept. Notes drawn before keep their note offs: drag a note's end to lengthen it. The help and the guide say what ends an arpeggiator run.
  • Renaming a kit and undoing it no longer leaves the kit marked "edited" (B-190). The undo now sends the stored name exactly.
  • Kit edits wait until the machine can take them (B-027). A value changed while an earlier edit was still on its way is no longer lost.
  • The GLOBAL page and window sizes are checked (B-186, B-063). Both editors' windows are covered by a test.

Machinedrum

  • The tempo nudge is no longer counted twice. When the editor reads GLOBAL while the nudge is held, it keeps the tempo the nudge started from, so letting go returns to the right tempo.
  • A press on the kit line of the lock lane snaps to the kit value. It no longer writes a lock beside it.
  • M, M, Alt+M in a row mutes every track (B-191). A late report from the machine used to undo the second mute, so one track stayed unmuted.

Both editors

  • SysEx import: the slot list is read again. Slots that were sent but not read back (Read back and compare off, or a slot given up) are now read again in the background, so the kit names listed match what the machine holds (B-174).
  • Shorter audio pauses when a project's state is loaded. The factory flash is shared under the device lock and copied outside it, so the audio thread waits less.
  • The Ableton note (B-187) is in the guide: Ableton keeps one window open per plug-in type by default (a host setting).

Linux

  • Text is visible on SteamOS and other minimal systems. The text of the menu bar and the native panels was blank when the system had no font whose name contains Sans, Verdana, Arial or Ubuntu. The editor now falls back to any available font.
  • The start-up failure card shows in full. When the web view cannot start, the native error is no longer covered by an empty browser window.

Emulator

  • Three fixes from the upstream projects, copied one at a time: the 68k core builds its opcode table once (std::call_once), so two editors starting together no longer race; the DSP's host port takes its pending flags with one atomic exchange; and AudioBuffer::append with size 0 no longer reads past the end. The sound is unchanged. The list is in doc/modern-ux/UPSTREAM.md.

Known

  • Monomachine: a GLOBAL change made while the editor is still reading the machine at project open may not reach the memory file (B-192). The change reaches the machine; it is being looked into.
